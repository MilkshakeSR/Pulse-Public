# Pulse – Mac Performance Monitor

A lightweight menu bar app that shows your Mac's CPU, memory, GPU, disk, network, battery and thermal status in real time.

## ⬇️ Download

[![Download Pulse](https://img.shields.io/badge/Download-Pulse.dmg-2ea44f?style=for-the-badge&logo=apple)](https://github.com/MilkshakeSR/Pulse-Public/releases/latest/download/Pulse.dmg)

Or see all versions on the [Releases page](https://github.com/MilkshakeSR/Pulse-Public/releases).

## Install
1. Open `Pulse.dmg`.
2. Drag **Pulse** into the **Applications** folder.
3. The first time you open it, right-click Pulse in Applications and choose **Open**, then click **Open** again.
   (Pulse isn't notarized by Apple, so macOS asks you to confirm once.)

## Requirements
- MacBook Air or MacBook Pro with Apple Silicon (M1 or newer)
- macOS 14 or later

## Uninstall
Quit Pulse from the menu bar, then drag it from Applications to the Bin.
